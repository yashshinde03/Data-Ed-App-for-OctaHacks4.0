# Data Ed App — OctaHacks 4.0

A data-education Streamlit application built for OctaHacks 4.0.

---

## INMT5526 Individual Assignment — docs/

The `docs/` directory contains the assignment report for INMT5526 Business Intelligence
(Semester 1, 2026).

| File | Description |
|------|-------------|
| `docs/assignment.md` | Assignment source (Markdown) |
| `docs/INMT5526_Assignment.docx` | Generated Word document (pre-built) |
| `docs/assets/erd.png` | ER diagram (generated by `docs/generate_erd.py`) |
| `docs/generate_erd.py` | Script to regenerate the ER diagram PNG |
| `docs/build_docx.py` | Script to regenerate the Word document |

### Regenerating the Word document

**Prerequisites**

```bash
pip install python-docx
sudo apt-get install graphviz   # or: brew install graphviz  (macOS)
```

**Steps**

```bash
# 1. Regenerate the ER diagram (requires Graphviz / dot)
python3 docs/generate_erd.py

# 2. Build the Word document
python3 docs/build_docx.py
```

The generated file will be saved as `docs/INMT5526_Assignment.docx`.

## Running the Streamlit App

```bash
pip install -r requirements.txt
streamlit run app.py
```
